# Farhan Basheer - Portfolio

Welcome to the official repository for **Farhan Basheer's Portfolio Website**. This project showcases my skills, experience, and projects as a Full Stack Developer, specializing in Django, Python, and modern web technologies.

## 🚀 Features

-   **Responsive Design:** Built with a mobile-first approach using Bootstrap, ensuring a seamless experience across all devices.
-   **Dynamic Content:** Powered by **Django**, allowing for easy management of portfolio items, skills, and testimonials.
-   **Interactive UI:** smooth scrolling, typed text effects, and modern animations.
-   **Contact Form:** Integrated contact form with email functionality.
-   **Legal Pages:** Dedicated Privacy Policy and Terms of Service pages.
-   **Blog/Project Showcase:** Detailed views for projects and case studies.

## 🛠️ Tech Stack

-   **Backend:** [Django](https://www.djangoproject.com/) (Python)
-   **Frontend:** HTML5, CSS3, JavaScript, [Bootstrap](https://getbootstrap.com/)
-   **Database:** PostgreSQL / SQLite (Development)
-   **Deployment:** PythonAnywhere / AWS (Support ready)

## 📦 Installation & Setup

Follow these steps to set up the project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/farhan-basheer-portfolio.git
    cd farhan-basheer-portfolio
    ```

2.  **Create a virtual environment:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up environment variables:**
    Create a `.env` file in the project root and add your configuration (Secret Key, Debug, Database credentials, etc.).

5.  **Run migrations:**
    ```bash
    python manage.py migrate
    ```

6.  **Create a superuser (optional):**
    ```bash
    python manage.py createsuperuser
    ```

7.  **Run the development server:**
    ```bash
    python manage.py runserver
    ```

    Visit `http://127.0.0.1:8000/` in your browser.
